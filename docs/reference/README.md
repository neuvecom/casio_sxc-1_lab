# reference — 一次情報資料

SXC-1 の仕様・操作・プリセット構成を裏取りするための**一次情報**を置く場所です。

## 置くもの

- 公式 PDF マニュアル（例: `sxc-1_manual_ja.pdf`）
- 公式仕様シート、公式アプリの画面キャプチャ など

## 使い方

- ここに置いた資料を読み、確定情報を `docs/db_schema.md`・`docs/requirements.md`
  やプリセット初期データへ反映する。
- 抽出した情報には出典（資料名・ページ）を併記する。
- メーカー非公開の項目や推測は「※未確認」と明記し、確定情報と混ぜない。

> 追加してコミット／プッシュしてください（または別途共有してください）。

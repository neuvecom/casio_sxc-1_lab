# 要件定義（ドラフト）

> 状態: ドラフト。確定したら本書を更新。※未確認 は一次情報で裏取りが必要な項目。

## 1. 背景・課題

CASIO SXC-1 は公式の全プリセット名一覧が**非公開**（公式マニュアルにも掲載なし）。
ユーザーは 1280スロット（80バンク × 16パッド）の中身・空き状況を把握しづらい。

## 2. 解決方針（管理者キュレーション型）

- **プリセット DB は管理者が作成・整備する**。管理者が実機を鳴らしながら音色を
  採取し、管理者専用ページから音色名・カテゴリ・由来などを登録する。
  （※公式リストが無いため、ユーザー参加型ではなく管理者が一次情報源を担う）
- **一般ユーザー**は、その DB を参照して
  - 自分のメモ・★評価を記録
  - お気に入りプリセットを登録
  - 自分の機体での配置・空き状況を管理
- **ユーザーが集まったら**、お気に入り集計に基づく**人気プリセットランキング**を公開。

## 3. 利用者ロール

| ロール | できること |
| --- | --- |
| 管理者（運営：1名想定） | プリセット DB の追加・編集・削除（管理者ページ）。一般機能も利用可 |
| 一般ユーザー（ログイン） | プリセット閲覧、メモ・★評価・お気に入り登録、自分の配置管理 |
| 未ログイン | （将来）公開ランキング等の閲覧のみ ※要検討 |

## 4. スコープ

### フェーズ0（管理者ツール）

- **管理者ページ**: プリセットの登録・編集 UI
  - 入力: 音色名 / カテゴリ / 由来（SK-1 等）/ 既定バンク・パッド / 説明・タグ
  - ※試聴用の音声サンプルは不要（ユーザーは実機を所有している前提）

### フェーズ1（一般ユーザー向け）

- 認証: Google ログイン / メールアドレス（Firebase Authentication）
- プリセット一覧・検索・詳細閲覧（管理者作成 DB）
- 自分の **1280スロットの空き状況ビジュアライズ**（80バンク × 16パッド grid）
- 各スロット／プリセットへの ★評価・メモ・お気に入り登録

### フェーズ2（コミュニティ）

- **人気プリセットランキング**（お気に入り数・★平均の集計を公開）

### 任意（将来）

- マイク入力（Web Audio API）による音色傾向の自動タグ付け補助
- MIDI 連携（`SXC-1_MIDI_JA.pdf` 準拠）

## 5. 主要ユースケース

1. （管理者）実機を鳴らしながら管理者ページでプリセットを1件ずつ登録する
2. （ユーザー）ログインして自分の 1280スロットの空き／埋まりを一覧で確認する
3. （ユーザー）プリセットにメモ・★評価を付け、お気に入りに登録する
4. （フェーズ2）人気プリセットランキングを見る

## 6. 非機能・制約

- 端末: PC / スマホのブラウザ（レスポンシブ）
- 文言: 日本語（UI も日本語を基本）
- 権限: 管理者操作は厳格に保護（Firebase のロール管理＝後述）
- 一次情報: 仕様は公式マニュアル等で裏取りし出典を併記

## 7. 用語

- **スロット**: バンク×パッドの1マス（全1280）。1音を保持
- **プリセット**: 工場出荷時に収録された音色（約208音 ※未確認）。管理者が DB 化
- **サンプル**: ユーザーが録音・登録した音

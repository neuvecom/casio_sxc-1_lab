# 要件定義（ドラフト）

> 状態: ドラフト。確定したら本書を更新。※未確認 は一次情報で裏取りが必要な項目。

## 1. 背景・課題

CASIO SXC-1 は公式の全プリセット名一覧が**非公開**（公式マニュアルにも掲載なし）。
ユーザーは 1280スロット（80バンク × 16パッド）の中身・空き状況を把握しづらい。

## 2. 解決方針

- **ユーザー参加型 DB**: 公式リストが存在しないため、音色名・カテゴリ・由来を
  ユーザーが協力して登録・編集していく（Wikipedia 型）。
- 全ユーザー共通の識別子は「**バンク番号 × パッド番号**」のみ。
- 各ユーザーの個別データ（★評価・メモ・自分の機体での配置）は分離して管理。

## 3. スコープ

### フェーズ1（基盤・自分用＋α）

- 認証: Google ログイン / メールアドレス（Firebase Authentication）
- 1280スロットの**空き状況ビジュアライズ**（80バンク × 16パッド grid）
- 各スロットへの登録: 種別（プリセット / 自分のサンプル / 空き）、音色名、★評価、メモ
- 共有プリセット情報の閲覧・追記（クラウドソーシング DB）

### フェーズ2（共有・コミュニティ化）

- 他ユーザーのメモ・使い方の閲覧
- 人気プリセットランキング（★平均・お気に入り数の集計）

### 任意（将来）

- マイク入力（Web Audio API）による音色傾向の自動タグ付け補助
- MIDI 連携（`SXC-1_MIDI_JA.pdf` 準拠）

## 4. 主要ユースケース

1. ログインして自分の 1280スロットの空き／埋まりを一覧で確認する
2. あるスロットに「何を入れたか」「★評価」「メモ」を記録する
3. 共有 DB で他ユーザーが特定したプリセット音色名・由来を調べる／自分も追記する
4. （フェーズ2）人気プリセットのランキングを見る

## 5. 非機能・制約

- 端末: PC / スマホのブラウザ（レスポンシブ）
- 文言: 日本語（UI も日本語を基本）
- データ整合性: 共有 DB は荒らし対策（編集履歴・要ログイン）を将来検討 ※要検討
- 一次情報: 仕様は公式マニュアル等で裏取りし出典を併記

## 6. 用語

- **スロット**: バンク×パッドの1マス（全1280）。1音を保持
- **プリセット**: 工場出荷時に収録された音色（約208音 ※未確認）
- **サンプル**: ユーザーが録音・登録した音

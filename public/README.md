# public/ 静的ファイル

ここに置いたファイルは、ビルド時にそのままサイト直下へ配信されます（例: `public/sxc-1.jpg` → `/sxc-1.jpg`）。

## トップページの実機写真

トップ（`/`）のヒーロー画像は **`/sxc-1.jpg`** を参照しています。
お手元の SXC-1 の写真を **`public/sxc-1.jpg`** として置いてください
（無い場合はプレースホルダーが表示されます）。

- 推奨: 横長〜4:3 程度、長辺 1200〜1600px、容量は数百KB以内に圧縮
- ファイル名を変える場合は `src/pages/Home.jsx` の `src="/sxc-1.jpg"` も合わせて変更

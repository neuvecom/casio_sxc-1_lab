# アイデア: WAV 照合によるプリセット由来の同定

## 背景・狙い

SXC-1 のプリセット由来は公式非公開（公式が挙げるのは SK-1 / MT-40 のみ、SK-5・CZ-101 は※未確認）。
耳での推定ではなく、**WAV同士の波形照合**で由来を「確定」させる。

- 比較対象A: **Waves Place** で販売されている実機（MT-40 / SK-1 等）の WAV データ（要購入）
- 比較対象B: SXC-1 から**コンパニオンアプリ経由でダウンロードした WAV**
- 同一録音なら波形レベルで一致 → 高精度に同定可能。**重複配置の検出**も同時にできる。

## 想定パイプライン（オフラインのローカル実行スクリプト）

アプリ本体とは別ツール（Python: numpy / librosa など）。

1. 前処理: 48kHz・モノ化、無音トリム、ピーク正規化
2. 照合:
   - 同一録音が濃厚 → 正規化後の相互相関 / ハッシュで“ほぼ一致”を検出（高速・高信頼）
   - 加工・再サンプル → MFCC＋コサイン類似度 / DTW でファジー一致
3. 出力: `本体WAV → 最も近い Waves Place 音 + 類似スコア` の対応表（CSV）
   - 高スコア=自動確定、曖昧=要確認の二段構え
4. 副産物: 本体内の重複クラスタを自動抽出

## アプリ連携

- 出力 CSV を管理者ページの**一括取り込み**につなげ、由来欄を自動入力
- 同定済み=由来「確定」、それ以外=「推定／不明」として DB に記録

## 留意点

- Waves Place は有料データ。**個人利用の範囲**で同定に使う。音源そのものは再配布しない。
- 完全自動で100%にはならない前提（自動確定／要確認の二段構え）。

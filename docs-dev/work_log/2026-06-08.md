# 作業ログ 2026-06-08

## 概要

「プリセットの由来（元機種）同定」を WAV 照合で試み、結果として**由来データを
アプリから外す**方針転換に至った。あわせて照合ツールを大幅に改良し、調査の事実を記録。

## 実施内容

### WAV 照合ツールの改良（scripts/wav_match/match.py）

- 本体WAV（`{bank}_/{pad}.wav`）と購入WAV（Waves Place）を照合する2段方式に：
  1. **完全一致**: PCM内容ハッシュ（同一録音・同一フォーマットなら確定）
  2. **スペクトログラム埋め込み**: 位相を無視し時間長を固定化した対数マグニチュード・
     スペクトログラムのコサイン類似度（再レンダリング/テンポ差/長さ違い/位相違いに対応）
- 当初の MFCC 統計量・波形相互相関は誤マッチ/再レンダリング非対応のため廃止。
- 実ファイル検証: 同一ループ ≒ 0.96 / 別音 ≦ 0.79 と明確に分離。
- 購入音源の有り/無しカバレッジ出力（`--coverage`）も追加。

### 重要な発見（前提の修正）

- 本体プリセット **221件中、購入データと完全一致は22件のみ**。
- 残りは「加工・再レンダリング」「アレンジ/派生（購入セットに同一なし）」「オリジナル」。
- → SXC-1 のプリセットは**元機種の音をそのまま収録したものではない**。
  由来を断定できるのは完全一致した一部だけ。公式が「SK-1/MT-40 を“使った”
  hip-hop 中心の音」とするのと整合。

### 方針転換：由来データを保持しない

- プリセットから `origin` と照合結果 `match` を**廃止**。
  - アプリUI（バンク一覧ツールチップ・スロット詳細・プリセットカード・管理フォーム/一覧）
    から由来表示・origin入力を撤去。
  - `import_matches.mjs` に `--clear-all` を追加し、Firestore の origin/match を一括削除。
- レトロ機の再現は「**ユーザーが購入サンプルを各スロットに登録（type=sample）**」で対応。
- 調査・照合ツールと元機種音色リファレンスは記録として残す
  （`scripts/wav_match/` / `docs/reference/`）。

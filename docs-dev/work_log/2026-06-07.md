# 作業ログ 2026-06-07

## 概要

CASIO SXC-1 プリセット／バンク管理 Web アプリの初期構築。構想段階のリポジトリから、
認証・バンク管理・プリセット DB・管理者ページまで動く MVP を一気に立ち上げた。
作業ブランチ: `claude/zealous-turing-80e95`。

## 実施内容

### 1. リポジトリ整備・設計

- `CLAUDE.md` を整備（当初 `main` に別プロジェクト「Hebodan」の内容が混入していたため
  SXC-1 用に修正。共通の作業ルールは維持）。
- 公式マニュアル PDF を `docs/reference/` に格納（ガイドブック等4点）。
- 重要な確定事項: **公式マニュアルにもプリセット一覧・バンク配置の記載が無い**。
  → プリセット DB は **管理者キュレーション型**（管理者が実機を採取して登録）で構築する方針に確定。
- `docs/requirements.md` / `docs/db_schema.md` を作成（管理者キュレーション型）。
- 技術スタック確定: **Vite + React + React Router + Firebase + Tailwind v4**。

### 2. 基盤・認証

- Vite + React の雛形、Firebase 初期化（未設定でも起動する設計）。
- 認証（Google / メール）、`ProtectedRoute`、マイページ。
- `firestore.rules`（個別データは本人のみ／プリセットは管理者のみ書込）、
  `firebase.json`、接続手順 `docs/firebase_setup.md`。

### 3. バンク空き状況

- 1280スロット（80×16）のグリッド表示と Firestore 永続化（`users/{uid}/slots`）。
- パッドクリックでモーダル編集（プリセット割当／サンプル名／メモ）。
- 割当プリセットの色をパッドに反映＋「P」表示。ホバーで独自ツールチップ（名前＋説明）。

### 4. プリセット DB（管理者・ユーザー）

- 管理者ページ: プリセット CRUD。管理者権限は Custom Claims `admin:true`
  （付与スクリプト `scripts/setAdmin.mjs`）。
- プリセット項目: 音色名 / カテゴリ / グループ(1〜16) / 色(8色) / 由来 /
  プリセットフラグ / ワンショット / ループ / BPM / 既定バンク・パッド / 説明 / タグ。
- 一般ユーザー向けプリセット一覧: お気に入り・★評価・メモ（`users/{uid}/userPresetMeta`）、
  検索・お気に入りフィルタ。
- 管理者の登録済み一覧: バンク切替タブ（B1〜B14／未設定／すべて）、編集・削除はアイコン化。
